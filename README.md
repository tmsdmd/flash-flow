# FlashFlow

FlashFlow هو مساعد تعلم شخصي محلي يعمل بالكامل على الجهاز، بدون إنترنت. يتيح للمستخدم:

- رفع ملفات نصية أو Markdown أو JSON
- لصق النص يدويًا
- تحليل المحتوى تلقائيًا
- استخراج الكلمات الأساسية
- إنشاء ملخص سريع
- توليد بطاقات فلاش كارد
- مراجعة البطاقات باستخدام نظام أساسي للتعلم المتكرر
- حفظ البيانات محليًا داخل المتصفح

## المميزات الحالية

- واجهة عربية احترافية
- دعم ملفات نصية وملاحظات
- تحليل نصي ذكي محلي
- بطاقات فلاش كارد تلقائية
- مراجعة مباشرة
- حفظ محلي عبر `localStorage`
- دعم PWA للاستخدام دون إنترنت

## التشغيل

### مباشرة من المتصفح

1. افتح `index.html` في المتصفح.
2. اختر ملفًا أو الصق النص.
3. اضغط على `إنشاء بطاقات ذكية`.
4. ابدأ المراجعة.

### كـ تطبيق محلي عبر خادم بسيط

يمكنك استخدام أي خادم محلي بسيط مثل:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

## الخطة القادمة

- دعم ملفات PDF وDOCX
- OCR للصور
- أسئلة متعددة الاختيارات
- نظام spaced repetition متقدم
- دعم الذكاء المحلي عبر llama.cpp
- تحويل التطبيق إلى سطح مكتب عبر Tauri
- دعم PWA كامل عبر التثبيت

## هيكل المشروع

- `index.html` – الواجهة الرئيسية
- `styles.css` – التنسيق العام
- `app.js` – منطق تحليل النص وإنشاء البطاقات والمراجعة
- `manifest.json` – إعدادات التطبيق الكاملة
- `service-worker.js` – خدمة التشغيل بلا إنترنت

## ملاحظة
