# FlashFlow

مساعد تعلم شخصي محلي يعمل دون إنترنت، يقرأ الملفات أو النصوص، ويحوّلها إلى ملخصات وبطاقات فلاش كارد ومراجعة ذكية.

## المميزات
- رفع ملفات نصية/Markdown
- لصق النص مباشرة
- تحليل المحتوى تلقائيًا
- إنشاء ملخص سريع
- توليد بطاقات فلاش كارد
- مراجعة البطاقات محليًا
- حفظ البيانات داخل المتصفح
- دعم التشغيل دون اتصال

## التشغيل
1. افتح `index.html` في المتصفح.
2. اختر ملفًا أو الصق نصًا.
3. اضغط على `إنشاء بطاقات ذكية`.
4. ابدأ المراجعة.

## التقنيات
- HTML / CSS / JavaScript
- PWA للـ offline
- localStorage لحفظ البيانات

## هيكل المشروع
- `index.html`
- `styles.css`
- `app.js`
- `manifest.json`
- `service-worker.js`
- `README.md`
